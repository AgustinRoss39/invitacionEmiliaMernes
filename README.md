# Invitación Emilia Mernes — Ross Digital Studio

Versión modernizada del modelo temático Emilia Mernes.

La invitación conserva la estética violeta/rosa, las imágenes rotativas, la foto, cinta, tipografía y música del modelo histórico, con estructura limpia, responsive y personalización centralizada en `js/config.js`.

Diseñado por Ross Digital Studio.
