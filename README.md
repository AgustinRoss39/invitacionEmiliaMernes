# Invitación Emilia Mernes — Ross Digital Studio

Versión modernizada del modelo temático Emilia Mernes.

## Estructura

- `index.html`: estructura principal.
- `css/styles.css`: diseño responsive y estética pop violeta/rosa.
- `js/config.js`: datos editables del evento y referencias de assets.
- `js/app.js`: contador, música, imágenes rotativas, WhatsApp, animaciones y ajuste automático del nombre.

## Personalización rápida

Desde `js/config.js` se pueden cambiar nombre, edad, mensaje, fecha, horario, lugar, dirección, Google Maps, WhatsApp e Instagram.

## Funciones

Pantalla de entrada con música, imágenes rotativas, contador regresivo, ubicación, botón “Cómo llegar”, confirmación por WhatsApp, animaciones al hacer scroll, diseño mobile-first y firma de @rossdigitalstudio.

Los personajes se posicionan con margen superior para evitar el problema de recorte visto en algunos modelos anteriores. Para esta versión demo, imágenes, tipografía y audio se cargan desde el repositorio histórico de DigitalRoss.
